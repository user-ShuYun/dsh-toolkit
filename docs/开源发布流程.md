# 开源发布流程（这台机器上的标准操作）

> 从「本地一堆脚本」到「GitHub 上能看的仓库」，一共六步。踩过的坑写在最后。

---

## 一、公开还是私有？先做决定

| 选项 | 命令 | 后果 |
|---|---|---|
| 公开 | `gh-publish --repo x --dir y` | 任何人可看、可克隆、可 fork；**不可逆地进了搜索引擎之前都不算晚** |
| 私有 | 追加 `--private` | 只有自己可见，适合含商业内容的仓库 |

**默认是公开**。所以第二步必须做。

---

## 二、发布前扫描（最重要的一步）

在仓库目录里跑：

```powershell
# 1) 凭据
Select-String -Path *.md,tools\*,docs\* -Pattern 'gh[pousr]_\w{20,}','sk-\w{20,}','password\s*[:=]' -AllMatches

# 2) 绝对路径（会暴露本机目录结构）
Select-String -Path *.md,docs\* -Pattern 'D:\\' -AllMatches

# 3) 大文件（不要推模型、视频、安装包）
Get-ChildItem -Recurse -File | Where-Object Length -gt 5MB
```

判定标准：

- **凭据 0 处** —— 一个都不能有（`.secrets/` 永远不进仓库）
- 绝对路径尽量改成 `$WORKSPACE` 之类的占位符
- 单文件 < 5 MB，整仓 < 50 MB（GitHub 对大文件不友好）

---

## 三、整理目录

只拷「别人拿去能跑」的东西：

```
repo/
├─ README.md        能力和边界（别只写功能，写实测数据）
├─ LICENSE          MIT
├─ .gitignore       node_modules / *.log / *.mp4 / *.png / .secrets
├─ tools/           脚本
├─ workflows/       ComfyUI API 工作流
└─ docs/            经验文档
```

**不要**放进：模型权重、输出视频、`node_modules`、token、日志、`.git` 残留。

---

## 四、拿 token（不需要用户手点）

前提：Edge 已经登录过 GitHub。

```powershell
# 1) 打开建 token 页面（repo 权限、备注预填）
#    https://github.com/settings/tokens/new?scopes=repo&description=<repo>

# 2) 用 CDP 填 note → 勾 repo → 点 Generate token
#    再从页面抓 ghp_ 开头的 40 位字符串

# 3) 写进 $WORKSPACE\.secrets\gh-token（不进仓库）
```

GitHub 建 token 没有 API，只能走网页；但网页可以用 CDP 自动点。
**若账号开了 2FA，会多一步验证，需要人工。**

---

## 五、推送

```powershell
node tools/gh-publish.mjs --repo <名字> --dir <目录> --desc "<一句话>"
```

走 GitHub REST API（blob → tree → commit → ref），不依赖 git 协议——因为部分网络下 git over HTTPS 会被重置。

输出会打印 commit 号和仓库地址。

---

## 六、验证

```powershell
# 用 API 确认可见性和文件列表
GET https://api.github.com/repos/<owner>/<repo>          → private / visibility / size
GET https://api.github.com/repos/<owner>/<repo>/contents  → 根目录文件名
```

## 踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 直接推工作区 | 带上 2.7 GB 构建缓存、绝对路径、`.secrets` | 建独立发布目录，只拷必要文件 |
| `.gitignore` 不挡目录 | `*.mp4` 挡得住文件，挡不住整个 `out/` | 只拷子目录，不要 `git add .` |
| token 30 天过期 | 到期推送报 401 | 重新走第四步；或建 fine-grained token 设更长有效期 |
| 忘记脱敏绝对路径 | README 里全是 `D:\用户名\...` | 用 `$WORKSPACE` 占位 |

---

## 安全提醒

- token 等价于密码：**能推送你的所有仓库**
- 放在 `.secrets/` 且该目录不在任何仓库里
- 机器共享/借人就撤销：GitHub → Settings → Developer settings → Tokens → Delete
- 用完即撤也是一种选择：需要时再生成，成本只有 20 秒
